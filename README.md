# Computer Architecture Explorer

A client-side educational website for learning computer architecture, built with plain HTML, CSS, and JavaScript for direct deployment on GitHub Pages.

## Run locally

Open `index.html` directly in a browser, or run a simple local web server:

```bash
cd computer-architecture-explorer
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Upload the project to a repository and enable GitHub Pages from the repository settings using the root folder as the site source.

## Features

- Interactive architecture map
- CPU, memory, storage, bus, and I/O explanations
- Fetch-decode-execute cycle animation
- Binary and hexadecimal converters
- Scheduling simulator
- Searchable glossary
- LocalStorage progress and bookmarks
- Responsive educational UI
