Component

CPU

Simple definition

The CPU is the main processing unit that executes instructions and controls the computer.

Technical definition

The central processing unit reads instructions, manages the execution flow, and coordinates arithmetic, logic, and memory operations.

What it does

It performs calculations, compares values, and directs data movement across the system.

Why it matters

Without the CPU, a computer cannot interpret instructions or run programs.

Example

A calculator app uses the CPU to add numbers and update the display.

Related components

RAM, registers, cache, buses, memory, and storage.

CPU vs GPU

Specialized processing

CPU

  • Main purpose: general-purpose control and logic
  • Architecture: a few powerful cores
  • Parallelism: moderate
  • Typical workloads: operating systems, apps, logic
  • Examples: browser, spreadsheet, compiler

GPU

  • Main purpose: parallel graphics and large datasets
  • Architecture: many smaller cores
  • Parallelism: very high
  • Typical workloads: rendering, AI, simulations
  • Examples: video playback, 3D graphics, ML

Architecture

32-bit vs 64-bit

32-bit

Smaller address space and fewer memory-addressing options.

  • Legacy compatibility
  • Older software
  • Limited address range

64-bit

Much larger address space and broader memory support.

  • Modern operating systems
  • Large memory support
  • Often runs 32-bit software in compatibility mode

Virtual Memory

Storage can extend available memory

RAM │ Active data │ Memory pressure ↓ Storage

Virtual memory allows the operating system to use storage as an extension of RAM when memory becomes tight. Paging moves blocks of data between memory and storage.

RISC vs CISC

Instruction set design

RISC

  • Simpler instruction design
  • Often fixed-length instructions
  • Load/store style is common
  • Focus on simple operations

CISC

  • More complex instructions
  • Often variable-length instructions
  • Memory operations can be integrated into instructions
  • Focus on richer instructions
